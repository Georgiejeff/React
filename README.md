# React Starter Studio

A responsive React + Vite learning site with searchable lessons, copyable examples, lesson completion tracking, and an interactive useState counter playground.

## Run locally
```bash
npm install
npm run dev
```

## Production build
```bash
npm run build
```

## Deploy on Render
Use a Static Site connected to this repository. Build command: `npm install && npm run build`. Publish directory: `dist`.

Progress is stored in the current page session only; this starter does not include account authentication or cloud database storage.
